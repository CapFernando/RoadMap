Abra demandas por HTTP, sem passar pela tela. Serve para automação — alerta de monitoramento, script, integração com outra ferramenta. Para abrir na mão, use + Nova demanda no topo: dá no mesmo.

Demais funções

        
Todas usam o mesmo token do passo 1. Identificam a
          demanda por codigo (aceita AX-42, ax42) ou por
          id.

        

      


      

        
Campos de "demanda-nova"

        

          
tituloobrigatóriotexto curto, mínimo 3 letras

          
tipoobrigatóriosustentacao (Erro/Bug) ou evolucao (Melhoria)

          
tema_idobrigatórioo código entre aspas, da lista abaixo

          
descricaoopcionalo que aconteceu, como reproduzir

          
status_planejamentoopcionalem_andamento (padrão), planejado ou backlog

          
entregaopcionalAAAA-MM-DD

          
solicitanteopcionalquem pediu; em branco fica você

        que a API faz é entregar para validação — quem fecha é o PM/PO, na tela dele.

        aguardando validação ela fica congelada: qualquer alteração responde
