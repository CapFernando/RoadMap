🔗 Gerar link de acesso para devs

Cole abaixo o token do GitHub com permissão de escrita no repositório. O sistema monta o link pronto para você copiar e repassar.

Crie um token em github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) com escopo repo.

⚠️ Envie este link por canal seguro (WhatsApp direto, não grupos). Quem tiver o link consegue escrever no repositório.

📋 Como funciona

1 Você gera o link acima e repassa para os devs (um link único serve para todos).
2 O dev abre o link → é autenticado automaticamente → digita a senha de acesso → escolhe o próprio nome.
3 O token fica salvo no dispositivo. Da próxima vez o dev pode abrir dev.html diretamente sem o link.
4 Tudo que o dev salvar aparece automaticamente no Admin, Gantt e Projetos — é o mesmo arquivo de dados.
